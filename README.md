# Drift-Sense: AI-Powered Navigation-Error Recovery for Wafer Inspection Tools

## 1. Overview

Drift-Sense localizes a reference semiconductor-pattern image inside a larger search image.

The localization pipeline combines:

* Multi-scale OpenCV template matching
* Candidate generation
* Non-Maximum Suppression (NMS)
* CNN-based candidate verification
* Hybrid OpenCV + AI candidate selection
* Targeted candidate-selection logic for difficult localization cases

The final output is the predicted center coordinate of the reference pattern inside the search image:

```text
x y
```

Example:

```text
394.00 417.00
```

---

## 2. Problem Definition

### Input

Two grayscale images:

1. Reference image
2. Search image

The reference pattern occurs somewhere inside the larger search image.

### Output

The predicted center coordinate `(x, y)` of the reference pattern within the search image.

The inference script is designed to run directly on test image pairs without manual source-code changes.

## 6. Dataset Generator

The standalone dataset generator is:

```text
src/generate_dataset.py
```

The submitted configuration uses the **DRAM** architecture option.

The generator accepts:

* Architecture style
* Number of pairs
* Output directory

### Generate a DRAM sample dataset

The hackathon dataset-generation workflow is demonstrated with 30 randomized pairs:

```powershell
python .\src\generate_dataset.py `
    --architecture DRAM `
    --pairs 30 `
    --output .\sample_dram
```

The generator creates reference/search image pairs and records the true reference-pattern center coordinates in:

```text
sample_dram/ground_truth.csv
```

The ground-truth CSV contains:

```text
pair_id
reference
search
center_x
center_y
target_width
target_height
```

Example:

```text
pair_id,reference,search,center_x,center_y,target_width,target_height
1,sample_dram\pair_001\reference.png,sample_dram\pair_001\search.png,382.0,407.0,128,128
2,sample_dram\pair_002\reference.png,sample_dram\pair_002\search.png,502.5,370.5,77,77
```

The generator therefore preserves the exact ground-truth center for every generated pair.

## 9. Localization Pipeline

The overall pipeline is:

```text
Reference Image + Search Image
              |
              v
   Multi-Scale OpenCV Matching
              |
              v
      Candidate Generation
              |
              v
      Non-Maximum Suppression
              |
              v
       CNN Verification
              |
              v
  AI Accepted / Rejected Candidates
              |
              v
    Hybrid Candidate Selection
              |
              v
        Predicted (x, y)
```

### Multi-scale search

The reference pattern is evaluated over multiple scales:

```text
0.85 -> 1.15
```

with a scale step of:

```text
0.01
```

### Candidate reduction

Spatial NMS is used to reduce nearby duplicate detections.

The verified system uses a 20-pixel NMS distance.

### Candidate verification

OpenCV-generated candidates are passed to the CNN verification stage.

The final selection combines OpenCV matching evidence and CNN confidence, with additional targeted selection logic for ambiguous cases.
